# Starter corpus

`agriculture_corpus.txt` is an illustrative, synthetic starter corpus authored for demonstrating the training pipeline. It is not a curated or scientifically validated agricultural dataset, and it should not be cited as an external source.

For a stronger project, replace or augment it with public-domain, openly licensed, or permissioned agricultural extension material. Record each source's title, publisher, URL, license, publication date, region, and preprocessing steps in a source manifest. Keep regional recommendations distinct and avoid mixing incompatible practices. Never include private farm or personal data without authorization.
